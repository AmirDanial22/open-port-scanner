Common Ports Explained

Educational guide to the 25 ports scanned by OPCF.
Understand what each port does and why it matters.

21 HIGH RISK
FTP
File Transfer Protocol

Uploads and downloads files between client and server. Transmits data and passwords in plain text.

22 MEDIUM
SSH
Secure Shell

Secure encrypted remote login and file transfer. Modern replacement for Telnet.

23 HIGH RISK
Telnet
Telnet Protocol

Old remote login protocol. Everything sent in plain text — extremely insecure.

25 HIGH RISK
SMTP
Simple Mail Transfer Protocol

Default port for sending emails. Frequently abused for spam and open-relay attacks.

53 MEDIUM
DNS
Domain Name System

Translates domain names (google.com) into IP addresses.

80 LOW
HTTP
Hypertext Transfer Protocol

Standard unencrypted web traffic (normal websites).

110 MEDIUM
POP3
Post Office Protocol v3

Used by email clients to download emails from server.

135 HIGH RISK
RPC
Remote Procedure Call

Microsoft service allowing programs to execute code on remote computers.

139 HIGH RISK
NetBIOS
NetBIOS Session Service

Legacy Windows file and printer sharing service.

143 MEDIUM
IMAP
Internet Message Access Protocol

Allows email clients to access and manage emails on the server.

443 LOW
HTTPS
Hypertext Transfer Protocol Secure

Encrypted and secure web traffic.

445 HIGH RISK
SMB
Server Message Block

Windows file/printer sharing (famous for EternalBlue vulnerability).

993 LOW
IMAPS
IMAP over SSL/TLS

Secure version of IMAP for email access.

995 LOW
POP3S
POP3 over SSL/TLS

Secure version of POP3 for downloading emails.

1723 HIGH RISK
PPTP
Point-to-Point Tunneling Protocol

Old VPN protocol — considered insecure by modern standards.

3306 HIGH RISK
MySQL
MySQL Database

Default port for MySQL database server.

3389 HIGH RISK
RDP
Remote Desktop Protocol

Windows Remote Desktop connection.

5432 HIGH RISK
PostgreSQL
PostgreSQL Database

Default port for PostgreSQL database server.

5900 HIGH RISK
VNC
Virtual Network Computing

Remote desktop and screen sharing protocol.

6379 HIGH RISK
Redis
Redis In-Memory Store

In-memory data store and caching system.

8080 MEDIUM
HTTP Alternate
HTTP Alternate Port

Alternative port used by web servers, proxies, and development tools.

8443 LOW
HTTPS Alternate
HTTPS Alternate Port

Alternative secure web port.

8888 MEDIUM
HTTP Alternate 2
HTTP Alternate Port 2

Common alternative web port (also default for Jupyter Notebook).

9090 MEDIUM
WebSM
Web-based System Management

Used for web-based system management and monitoring tools.

27017 HIGH RISK
MongoDB
MongoDB NoSQL Database

Default port for MongoDB NoSQL database.
