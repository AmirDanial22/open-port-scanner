Understanding Port Exposure

Network ports are like doors to a building. Knowing which doors are open helps you decide if they should be locked.

Remote Access CRITICAL

Ports: 22 (SSH) · 23 (Telnet) · 3389 (RDP) · 5900 (VNC)

These services allow remote login. If exposed to the internet, anyone with the right credentials — or a weak password — could gain full access.

Best Practice: Restrict to trusted networks or VPN only.
Database & Storage HIGH RISK

Ports: 3306 (MySQL) · 5432 (PostgreSQL) · 27017 (MongoDB) · 6379 (Redis)

These store your data. Making them public is like placing your file cabinet on the sidewalk — even if locked, it attracts unwanted attention.

Best Practice: Never expose directly. Keep behind application layers.
File Sharing & Management

Ports: 21 (FTP) · 445 (SMB) · 139 (NetBIOS)

Services for moving files around. Legacy versions are often insecure. Best kept within private home or office networks.

Best Practice: Do not open these to the public internet.
Web Services STANDARD

Ports: 80 (HTTP) · 443 (HTTPS) · 8080 (Alt Web)

Standard website ports — usually meant to be open so visitors can reach your site. Focus on keeping the software behind them up-to-date.

Best Practice: Keep web server software patched and current.
